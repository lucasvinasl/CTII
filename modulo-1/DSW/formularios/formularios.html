Elementos Estruturais

form - container principal - destino dos dados (action) e método de envio (method)

label - rótulo deu um campo. associado ao input por for="id_do_campo"

fieldset - agrupa logicamente campos relacionados dentro do form

legend - legenda de um fieldset

datalist - opções predefinidas para preenchidimento automático de um input

output - resultado da ação do usuário

Tipos de Input

tel

number - min, max, step

date/time/datetime-local

range - slider

color

search
