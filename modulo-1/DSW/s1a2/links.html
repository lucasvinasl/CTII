Principais Atributos da tag < a >

href - url do link

target - tipo de abertura do link: _sef(mesma aba), _blank(nova aba), _parent, _top

rel - relação entre o documento atual e o documento vinculado (SEO): noopener, noreferrer, nofollow, sponsored, author

download ou download="novo-nome.pdf" - navegador baixar o recurso

hreflang - idioma do documento (pt-BR, en, es)

type - tipo de mídia/MIME type - application/pdf, image, png

Exemplos de Uso

Nova Aba

Ao abrir links em uma nova aba com target="_blank", use obrigatoriamente rel="noopener" (evita que a nova página controle a página de origem via JS) e rel="noreferrer" (impede o envio do cabeçalho de referência).

Estilização CSS

/* 1. Unvisited (:link) - Link não visitado */ a:link { color: #0066cc; text-decoration: underline; } /* 2. Visited (:visited) - Link já visitado pelo usuário */ a:visited { color: #551a8b; } /* 3. Hover (:hover) - Quando o cursor passa por cima do link */ a:hover { color: #e63946; text-decoration: none; } /* 4. Active (:active) - No momento exato do clique */ a:active { color: #ff0000; } /* Estado de Foco (:focus) - Acessibilidade via navegação por teclado */ a:focus { outline: 2px solid #e63946; outline-offset: 3px; }
