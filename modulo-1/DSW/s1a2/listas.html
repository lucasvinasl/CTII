2 - Listas Ordenadas

Quando a ordem dos itens altera o sentd do conteúdo, ordem numérica ou cronológica.

tag < ol > declara a lista (order list)

tag < li > cada item da lista (list item)

  1. Mofásico
  2. Bifásico
  3. Trifásico

Estruturas de navegação, como menu de sites constumam ser listas envolvidas dentro de um container < nav >.

Alterando o Marcador

type como atributo da tabela

type 1

  1. Mofásico
  2. Bifásico
  3. Trifásico

type A ou a - letra maiúscula ou minúscula

  1. Mofásico
  2. Bifásico
  3. Trifásico

type I ou i - número romano maiúscula ou minúscula

  1. Mofásico
  2. Bifásico
  3. Trifásico

start - contagem inicial do marcador (letra ou número)

  1. Mofásico
  2. Bifásico
  3. Trifásico

reversed - contagem inicial em ordem decrescente/regressica do marcador (letra ou número)

é booleano, declara ou não declara

  1. Mofásico
  2. Bifásico
  3. Trifásico

value - aplicado a um item, força o valor do marcador pular

  1. Mofásico
  2. Bifásico
  3. Trifásico

Estilização do Marcador em CSS

ol { list-style-type: decimal; /* Padrão: 1, 2, 3... */ /* Outras opções: decimal-leading-zero (01, 02, 03...) lower-alpha / upper-alpha (a, b, c... / A, B, C...) lower-roman / upper-roman (i, ii, iii... / I, II, III...) lower-greek (α, β, γ...) */ }

/* Remove marcadores padrão e inicia um contador */ ol.custom-list { list-style: none; counter-reset: meu-contador; } /* Incrementa e exibe o contador no ::before ou ::marker */ ol.custom-list li { counter-increment: meu-contador; } ol.custom-list li::before { content: counter(meu-contador, decimal) ") "; color: #2a9d8f; font-weight: bold; }

3 - Listas de Descrição

Servem para associar termos a suas definições, pares de chave/valor, metadados de um artigo ou seções de perguntas e respostas (FAQ).

tag < dt > Description Term - Chave

tag < dd > Description Detail - Valor

No HTML5, é permitido agrupar pares dt/dd dentro de divs para facilitar o layout em CSS

HTML
Linguagem de Marcação de Hipertexto que define a estrutura do documento.
CSS
Linguagem de Folhas de Estilo que controla a apresentação visual do documento.

4 - Sublistas

Para criar listas dentro de listas, a nova lista < ul> ou < ol> deve ser inserida dentro da tag < li> do item pai, nunca solta diretamente entre dois < li >
