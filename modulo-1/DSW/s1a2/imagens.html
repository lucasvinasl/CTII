Atributos da tag img

src - caminho da imagem

alt - texto alternativo (SEO, imagem não renderizada)

widht/height - dimensões

srcset - lista de imagens

loading - lazy / eager - estratégia de carregamento

decoding - decodificação assíncrona - async (padrão), sync, auto

Estilização CSS

img { max-width: 100%; height: auto; display: block; /* Remove o espaço em branco indesejado na base de elementos inline */ } .card-avatar { width: 150px; height: 150px; aspect-ratio: 1 / 1; /* Atua como 'background-size: cover' */ object-fit: cover; /* Ajusta o ponto focal do corte */ object-position: center top; border-radius: 50%; }
